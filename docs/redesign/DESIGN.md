# Creative direction: Built beneath the surface

Original direction established after the existing-site and seven-reference rendered review. Dark graphite / ivory / electric chartreuse. Large locally bundled Space Grotesk headings, comfortable Manrope body, Plex Mono for useful technical labels. A procedural exploded stack visualizes interface, logic and data; pointer response and reversible scroll separation support that concept. No borrowed illustrations or source. Decorative canvas never owns content or scrolling.

## Architecture and tokens
Retain React/TypeScript/Vite and direct Three.js. Lazy-load new scene; no new animation framework needed. Normal anchors and native scrolling. Semantic sections: hero, work, about, skills, experience/education, featured credentials, archive, résumé, contact. Original source modules retained for traceability, new implementation lives in App, SystemScene and Credentials. Custom CSS defines background/surface/text/accent/border, spacing, maximum width, type, radii, easing and layer tokens. Breakpoints 1100/760/480. Mobile scene moves beneath title; static CSS architecture fallback for WebGL loss, disabled graphics and reduced motion. Intersection reveals use progressive enhancement with visible content by default. Pointer transforms disabled for reduced motion.

Motion: short opacity/translation, reversible scroll-driven layer separation, no scroll interception, no pinned reading sections. Pause offscreen/hidden canvas; cap DPR, share geometry/materials, dispose renderer/resources/listeners. Certificate dialog uses native modal focus and Escape; thumbnails load lazily. Original certificate PDFs remain downloadable; extensionless source receives an explicit PDF download name. No canonicals or sitemap domain invented: configure verified SITE_URL at build time.

## Supplemental interaction review
Mobile menu clicks were captured for Majd, Devsync, ReoPorto, Nightly, Algera and Portox. Majd expands a compact panel, Devsync a small white dropdown, ReoPorto a full-width dark navigation panel, Nightly a full-screen list with ruled rows, Algera a centered overlay, and Portox an inset pill-link panel. Portox's menu changed visually even though its body text comparison did not change. Michael's About was attempted by accessible link text (not found as an actionable link) and then by its visually observed navigation position. These are observations, not accessibility certification of those references. Their promotional overlays and low-contrast secondary copy are deliberately not adapted.
