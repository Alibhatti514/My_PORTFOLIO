# Studio reflection atlas

Precomputed CubeUV / PMREM reflection atlas baked from the Three.js RoomEnvironment procedural scene (Three.js MIT license, retained in node_modules/three/LICENSE). Generated by scripts/bake-studio-environment.mjs. This is environmental lighting data, not a photograph or portrait edit. Baking avoids running the room cubemap renderer and PMREM filter on every visitor's device. Linear color; CubeUVReflectionMapping; no generated mipmaps.
